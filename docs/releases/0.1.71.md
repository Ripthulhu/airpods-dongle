# AirPods Dongle 0.1.71

USB AAC-ELD playback can now catch up after a short scheduling delay while
the dongle still has audio queued. This prevents a small delay from turning
into an audible Bluetooth stream restart. Longer stalls and buffer overflows
still trigger recovery.

The USB motion interface skips work when no head-tracking report is ready.
On-demand diagnostics show how long motion reports take to handle and why the
audio stream last entered recovery.

In a three-minute PC listening test, Plexamp played through the Windows
head-tracking renderer with Game Mode on. The listener heard clean audio
throughout. The dongle sent 17,999 AAC-ELD units with zero stream restarts,
dropped frames or controller flushes. The microphone was idle.

The test used the firmware from commit `1ccfdfdebe90` before the version
bump. [Exact UF2 used for the listening test](https://github.com/Ripthulhu/airpods-dongle/releases/download/pc-listening-1ccfdfdebe90/airpods_dongle.uf2)
